; Edited for FyreChat
;
; There are four commands that the Aliases plugin provides:
; /rla - reload aliases. (Reloads this file)
; /la - list aliases. (Aliases marked with * have AwayReset set to 0, see below)
; /ea - edit aliases. (Opens Aliases.txt)
; /sc - show commands. (Use with parameter on/off, or no parameter to toggle)
; Commands shown with a yellow * have AwayReset set to 0, see below.
; If BinaryChat Plugin API revision 3 is present, the /sc setting is saved to the registry.
; The above commands never reset the away idle.

; Format for aliases:
; Alias|Cmd|AwayReset
; Alias: "Short" command. (No slash)
; Cmd: "Long" command.
; AwayReset: Boolean (0 or 1) specifying whether the away idle time should be reset
; after the command is processed. (0 false, 1 true)
; This is ignored for BinaryChat Plugin API versions lower than 3.
; If this is omitted, the default is 1.
